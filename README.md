# مصالحہ آرگنائزر | Spice Organizer

ایک جدید، تیز رفتار اور خوبصورت ویب ایپلیکیشن جو روایتی اور کسٹم مصالحہ جات کے نسخوں (Recipes) کے درست اوزان، تناسب اور گھریلو پیمائشوں کے انتظام کے لیے بنائی گئی ہے۔

> **A professional, offline-first spice formulation manager and dynamic ratio calculator crafted with React, TypeScript, and Tailwind CSS.**

---

## 🌟 نمایاں خصوصیات (Key Features)

- **خودکار فیصد تناسب (Dynamic Ratio Calculation):**
  ہر مصالحے کے گرامز درج کرتے ہی مجموعی وزن کی بنیاد پر ہر جزو کا فی صد تناسب فوراً بغیر کسی تاخیر کے خود بخود کیلکولیٹ ہوتا ہے۔
- **دوہری زبان کی معاونت (Dual Naming - Urdu & English):**
  ہر مصالحے کا روایتی اردو نام اور بین الاقوامی انگریزی نام ایک ساتھ نظر آتا ہے اور صارف ضرورت کے مطابق دونوں میں موقع پر ہی ترمیم کر سکتا ہے۔
- **آسان ترتیب بندی (Drag & Drop + Arrow Ordering):**
  ماؤس سے پکڑ کر (Drag & Drop) یا اوپر/نیچے تیر کے بٹنوں کی مدد سے مصالحوں کی ترتیب کو باآسانی اپنی مرضی کے مطابق ڈھالا جا سکتا ہے۔
- **گھریلو پیمائش کا انتظام (Household Measures):**
  گرامز کے ساتھ ساتھ گھریلو ضرورت کے مطابق چمچ، کپ یا عدد میں پیمائش درج کرنے، ترمیم کرنے یا خالی رکھنے کی مکمل آزادی۔
- **نسخہ ٹیمپلیٹس مینیجر (Recipe Templates Management):**
  تیار کردہ کسی بھی مصالحہ مکسچر کو مخصوص نام دے کر محفوظ کریں، بوقتِ ضرورت ایک کلک پر لوڈ کریں یا غیر ضروری ٹیمپلیٹ کو حذف کریں۔
- **صاف ستھرا پرنٹ اور پی ڈی ایف (Clean Print / PDF Export):**
  پرنٹ نکالتے وقت تمام فالتو بٹنز، ایڈٹ فیلڈز اور کنٹرولز چھپ جاتے ہیں اور پی ڈی ایف کے نچلے حصے میں فعال ٹیمپلیٹ کے نام کے ساتھ ایک شاندار مصالحہ کارڈ تیار ہوتا ہے۔
- **ایک کلک سمری کاپی (One-Click Summary Copy):**
  پورے نسخے اور ہر مصالحے کے وزن و تناسب کی مکمل تفصیلات واٹس ایپ یا پیغامات میں بھیجنے کے لیے ایک کلک پر کلپ بورڈ میں کاپی ہو جاتی ہیں۔
- **ڈیٹا بیک اپ و مکمل بحالی (Backup & Restore - Full Data Portability):**
  اپنے تمام مصالحوں کے اوزان، گھریلو پیمائشوں اور محفوظ شدہ ٹیمپلیٹس کو ایک کلک پر JSON بیک اپ فائل میں ڈاؤن لوڈ کریں۔ کسی بھی نئے کمپیوٹر، براؤزر یا نئے کلاؤڈ اکاؤنٹ پر اسی بیک اپ فائل کو منتخب یا ڈریگ اینڈ ڈراپ کر کے اپنا مکمل ڈیٹا لمحوں میں بحال (Restore) کریں۔
- **آف لائن اول اور کلاؤڈ سنک (Offline-First & Cloud Firestore Sync):**
  تمام تر ڈیٹا اور محفوظ شدہ ٹیمپلیٹس آف لائن بھی بغیر انٹرنیٹ کے براؤزر کی لوکل میموری اور IndexedDB کیش میں محفوظ رہتے ہیں۔ جیسے ہی انٹرنیٹ فعال ہوتا ہے، فائر بیس کلاؤڈ ڈیٹا بیس (`Cloud Firestore`) کے ساتھ خود بخود سنک ہو جاتا ہے۔

## 🛠️ تکنیکی بنیاد (Tech Stack)

## 📊 ڈیٹا سٹرکچرز (Core Data Models)

### `SpiceItem` (انفرادی مصالحہ)
```typescript
export interface SpiceItem {
  id: string;               // منفرد شناختی کوڈ
  name: string;             // اردو نام
  englishName: string;      // انگریزی نام
  weightGrams: number;      // وزن گرام میں
  householdAmount?: string; // گھریلو مقدار (مثلاً: 1، 2، 0.5)
  householdUnit?: string;   // یونٹ (چمچ، کپ، عدد، وغیرہ)
  householdMeasure?: string;// مشترکہ ڈسپلے سٹرنگ
}
```

### `RecipeTemplate` (محفوظ شدہ نسخہ)
```typescript
export interface RecipeTemplate {
  id: string;               // ٹیمپلیٹ آئی ڈی
  name: string;             // نسخے کا نام
  createdAt: string;        // تخلیق کی تاریخ
  spices: SpiceItem[];      // مصالحوں کی فہرست
}
```

## 🚀 شروع کرنے کا طریقہ (Getting Started)

### پیشگی شرائط (Prerequisites)
- [Node.js](https://nodejs.org/) (ورژن 18 یا اس سے نیا)
- این پی ایم (npm)

### انسٹالیشن اور رن کرنا
1. **پروجیکٹ ڈائریکٹری میں جائیں اور ڈیپینڈینسیز انسٹال کریں:**
   ```bash
   npm install
   ```

2. **ڈویلپمنٹ سرور چلائیں:**
   ```bash
   npm run dev
   ```
   ایپلیکیشن خود بخود مقامی ایڈریس پر لائیو ہو جائے گی۔

3. **ٹائپ اسکرپٹ لنٹنگ کی تصدیق:**
   ```bash
   npm run lint
   ```

4. **پروڈکشن بلڈ تیار کرنا:**
   ```bash
   npm run build
   ```
   تیار شدہ پرفارمنس آپٹیمائزڈ فائلز `dist/` فولڈر میں بن جائیں گی۔
